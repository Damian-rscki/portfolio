PROP · HMO

126 Pinhoe Road, Exeter — HMO Investment Analysis

Live
4-Bed Terrace, Class C4 · EX4 7HJ

An acquisition analysis for an already-licensed 4-bedroom HMO between Exeter's two university campuses. The property holds a certificate of lawfulness for 4 unrelated occupants (Class C4) and has planning potential for a 5th bedroom via conversion of the ground-floor living room.

  • Four comparable sales on the same street in the prior 18 months averaged £301,000 (range £294,000–£315,000), all sold in better condition than this property, which needs a substantial refurbishment.
  • Modeled across both the £325,000 asking price and a £270,000 negotiated price, and both the existing 4-bed layout and a 5-bed layout with the living-room conversion, using a shared refurbishment budget (£35,995 for 4-bed, £43,470 for 5-bed) and consistent financing assumptions (75% LTV, 5.5% mortgage rate, 12% management fee).
  • Returns benchmarked against 8% gross yield, 6% net yield, and 8% cash-on-cash ROI targets.
